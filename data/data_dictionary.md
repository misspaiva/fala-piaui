# Data Dictionary — Fala, Piauí

| Column | Description |
|---|---|
| `expression` | The original word or expression in Portuguese. It is not translated or standardized. |
| `meaning_pt` | A contextual explanation of the expression in Brazilian Portuguese. |
| `meaning_en` | An explanatory English rendering. It may not be a direct translation. |
| `locality` | City, area, or geographic context when known. Use a cautious note when unconfirmed. |
| `state` | Brazilian state associated with the record. The initial collection focuses on Piauí. |
| `category` | A broad English category describing the use or experience associated with the expression. |
| `example_pt` | An original example sentence in Portuguese. |
| `example_en` | An English rendering of the example sentence. |
| `record_source` | How the entry was recorded, such as personal memory, family speech, observation, reference work, or community contribution. |
| `confidence` | Initial confidence in the recorded use: `initial`, `medium`, or `high`. |
| `context_note_pt` | Context, variation, uncertainty, and limitations in Portuguese. |
| `context_note_en` | Context, variation, uncertainty, and limitations in English. |
